## Description

> - Flyers search defaults to a "Best match" sort. It used "Biggest savings", which put peanut butter and jam above butter. Any other sort can still be picked while searching.
> - A blank variant is now a value: it matches only a listing with no variant. Most flyer rows don't print one, so items like "PC peanut butter 750 g" were treated as incomplete and never matched. Brand, item and size are still required, and variant must still be equal.
> - The first flyer load waits up to 45 s instead of 5 s, so a cold warehouse doesn't make items saved right then look like they have no deal. Refreshes with a copy in hand stay on 5 s.
>
> ## Summary by Sourcery
>
> Improve flyer search relevance and ensure newly saved items can see matching deals during the initial flyer load.
>
> New Features:
> - Add relevance-based “Best match” sorting for flyer searches while retaining other sort options.
>
> Bug Fixes:
> - Match items with an explicitly blank variant to flyer listings that also have no variant.
> - Allow the initial flyer query more time to complete on a cold warehouse while keeping refreshes on the shorter timeout.
>
> Tests:
> - Add coverage for blank-variant matching and first-load versus refresh query timeouts.
