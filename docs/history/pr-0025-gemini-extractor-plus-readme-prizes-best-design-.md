## Description

> ## What this does
>
> **Gemini extractor (MLH Best Use of Gemini API).** Receipts, product photos and typed text can now be read with Google's Gemini API, behind the same `Extractor` interface and `Extraction` schema as Claude and `ai_query`.
> - `EXTRACTOR=gemini`, or automatic when `GEMINI_API_KEY` is the only key set (Claude stays the default when both are set). `GEMINI_MODEL` overrides the default, `gemini-3.5-flash` (`gemini-2.5-flash` is retired for new keys).
> - Called over REST with `httpx`: no new dependency. Key in a header, never a URL. Gemini is asked for schema-constrained JSON and the reply is validated; one retry on 429/500/502/503; every failure maps to the same 502/422 the other extractors use; the image type is sniffed from the bytes.
> - Checked live: typed text, a product photo and a receipt (store, total, 14 line items) parse, and `/intake/manual` and `/intake/photo` work end to end with `EXTRACTOR=gemini`.
> - 11 offline tests (`apps/api/test_gemini.py`); one existing health test now also clears `GEMINI_API_KEY`.
>
> **README.**
> - A "Prizes we're going for" table (Databricks, Best Design, Gemini, Community Impact, Freebuff), each linking to its evidence.
> - New animated cards and sections for Gemini and Freebuff; the banner strip and Devpost card include them.
> - Best Design: a checklist of what can be verified in the app and code (44 pt tap targets, persisted light/dark with a test, labelled icon buttons and live regions, reduced-motion shimmer, safe-area insets).
> - Community Impact: the problem from the design spec, what changes, and an honest note that savings are unmeasured.
> - `GEMINI_API_KEY` / `GEMINI_MODEL` in the env docs; the diagram names Gemini.
>
> ## Still to fill in (marked in the README)
> - The **Figma link**, here and on Devpost (the Best Design prize requires it).
> - **Specifics for Freebuff**: which parts it built or reviewed. The README only says the team used it alongside Claude Code.
> - The Freebuff mark is a generic terminal icon, and the Gemini star is a simple redraw, not official artwork.
>
> ## Checks
> - `ruff` clean, `pytest` 255 passed. No web code changed.
> - The Gemini API key lives only in a git-ignored `.env`; it is in no commit.
