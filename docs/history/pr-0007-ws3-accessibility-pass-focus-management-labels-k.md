## Description

> ## Summary
> Follow-up to the already-merged WS3 PRs (#3, #4) — a real accessibility audit, each finding verified by hand in the emulator:
>
> - **Focus management for all 7 bottom sheets** (one fix in \`Sheet.tsx\`): focus moves in on open, Tab is trapped inside, focus restores to the trigger on close.
> - **Form labels properly associated** with inputs (\`<label htmlFor>\`/\`id\` via \`useId\`) — screen readers previously had no idea which field was which.
> - **Visible focus rings** restored where \`outline-none\` had silently killed keyboard focus visibility.
> - **Swipe-to-delete is keyboard-operable** — Tab reveals the row, Enter deletes.
> - **Live status announcements** (\`role="status"\`) for Loading/error/empty transitions.
>
> Also caught and fixed a real regression along the way: the first version of the focus-trap effect depended on \`onClose\` directly, which some callers recreate every render (e.g. \`TypeOrSaySheet\` on every keystroke) — that re-stole focus to Cancel on every keystroke, breaking manual entry. The e2e suite caught it immediately; fixed with the standard ref pattern.
>

> - [x] Manually verified in the emulator: Tab wraps inside a sheet, Escape restores focus to the trigger, Tab+Enter deletes a list item
> - [x] \`make check-api\`, lint, typecheck all pass
