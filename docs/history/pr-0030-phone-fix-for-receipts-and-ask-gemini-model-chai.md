## Description

> ## What this does
> Everything that was still outstanding after the earlier merges, in four commits.
>
> **1. Receipts and Ask no longer fail on a phone when Gemini or Genie is slow or busy.** Three timeouts stacked up in front of the API (the app gave a receipt scan 30 s, the web proxy gave any call 30 s, and the API waited 60 s on Gemini).
> - The web proxy waits up to 180 s (`experimental.proxyTimeout`). Reproduced with a 40 s fake API: 500 at 31 s before, 200 at 40 s after.
> - A receipt scan gets 120 s in the app; other intake calls keep 30 s.
>
> **2. Gemini tries a chain of models and skips ones that just failed.** In a live test the main model was out of free-tier quota (429) and the single fallback was in a high-demand spell (503, 12 to 18 s to fail), so every attempt ran out.
> - `GEMINI_FALLBACK_MODEL` is a comma-separated list tried in order after the main model (default: `gemini-3.5-flash-lite`, `gemini-flash-lite-latest`, `gemini-3.1-flash-lite`).
> - A model that fails is skipped for a while (120 s after a quota refusal, 30 s after a server error, 60 s after a stall), shared across requests; if every model is cooling they are all tried anyway.
> - Checked live while the main model was out of quota: the first scan took 5.6 s, the next 3.2 s; the lighter model returned the same 14 items, sizes, store, date and total.
>
> **3. README:** Freebuff removed (section, card, prizes row, intro, banner strip, Devpost chips), and the flyer data described as "public flyer feeds" without naming the provider (plus a `make flyer-snapshot` alias of the existing command so the README can document it).
>
