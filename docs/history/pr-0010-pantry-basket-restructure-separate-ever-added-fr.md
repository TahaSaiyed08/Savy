## Description

> ## Summary
> Implements the requested information-architecture change:
>
> - **Pantry** (renamed from "My List") = every item ever added. **Basket** = the subset you're explicitly getting right now, tracked via a new `in_basket` flag.
> - Each Pantry row gets a third swipe action to move an item into/out of the Basket (alongside the existing Edit and Delete), with a small cart icon shown when an item is in the Basket.
> - Tapping an unswiped Pantry row jumps straight to that item's cheapest matching deal.
> - **Deals** renamed to **Add item(s)**, and made visibly more compact (smaller cards/text/spacing) to cut down on scrolling.
> - New `EditItemSheet` for fixing an item's brand/item/variant/size in place, backed by a new `PATCH /items/{id}` endpoint.
> - Backend: `in_basket BOOLEAN` column added to `user_items` (additive ALTER, applied live against the Databricks warehouse), `POST /items/{id}/basket` to toggle it, `/basket` now filters to only basket items. New manually-added items default **out** of the Basket; the 5 seeded demo items stay in it so the Basket tab is never empty on a fresh device.
> - Routes (`/list /deals /basket`) deliberately unchanged — only labels — since they're a frozen interface per `docs/plan.md`.
>
