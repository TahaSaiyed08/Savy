## Description

> Replaces the "Original flyer" text link with the row's own product image as the tap target (MatchCard, Closest-this-week, /flyers, Pantry/Basket rows), restructured or stopPropagation'd so it never nests inside a row's own button/swipe handler.
>
> Promotes the dev-only force-theme plumbing to a real light/dark switch in the header of all three tabs: migrates the old storage key, adds an anti-flash inline script, and keeps the PWA status bar color in sync.
>
> ## Summary by Sourcery
>
> Make product images the flyer-opening targets and promote theme overrides into a persistent light/dark setting across the app.
>
> New Features:
> - Add flyer-opening product image links across price-match, flyer, pantry, and basket item rows.
> - Add a persistent light/dark theme toggle to the Pantry, Flyers, and Basket headers.
>
> Bug Fixes:
> - Prevent flyer image interactions from triggering surrounding row actions or swipe handlers.
> - Prevent theme flashing on initial load and keep PWA status bar colors synchronized with the active theme.
>
> Enhancements:
> - Migrate the former development-only theme preference to the user-facing theme setting with system-theme fallback and storage-error handling.
>
> Tests:
> - Add end-to-end coverage for flyer image navigation, row interaction behavior, theme persistence, cross-tab consistency, reload behavior, and legacy theme-key migration.
> - Add unit coverage for theme preference persistence, migration, system fallback, and unavailable storage.
