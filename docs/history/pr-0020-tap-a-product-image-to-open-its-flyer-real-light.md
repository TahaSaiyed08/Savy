## Description

> ## Summary
> - **Flyer image as the tap target**: the row's own product image now opens the Flipp flyer in a new tab (`Thumb` gets an optional `href`), replacing the "Original flyer" text link. Wired into `MatchCard`, the "Closest this week" list, `/flyers`, and Pantry/Basket rows. No nested interactive elements — restructured siblings where there's a row button, `stopPropagation` where the image sits inside a swipeable row. Falls back to a plain (non-link) thumbnail when there's no URL (mock data, Volume pages).
> - **Real theme toggle**: promotes the dev-only `ForceTheme` plumbing (previously only reachable from `/dev/states`) to a user-facing light/dark switch in the header of all three tabs. Migrates the old `realdeal.dev.theme` storage key to `realdeal.theme` once, adds an anti-flash inline script in `layout.tsx` so the override applies before paint, and keeps `<meta name="theme-color">` in sync with the active theme.
>
> ## Test plan
> - [x] `npm run lint` / `tsc --noEmit` — clean
> - [x] `vitest run` — 53/53 passing, including new `ForceTheme.test.ts` (migration, persistence, storage-throwing)
> - [x] `playwright test` — 24/24 passing, including new `theme.spec.ts` (toggle persists across tabs/reload, old-key migration) and updated `basket-flyers.spec.ts` (image opens the flyer link in a new tab; row text still opens Price Match)
> - [x] Manually screenshotted Pantry/Basket/Flyers and the Price Match/flyer-zoom screen in both light and dark mode at iPhone size — toasts, sheets, skeletons, and the flyer zoom backdrop all look right in both themes
>
