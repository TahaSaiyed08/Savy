## Description

> ## What this does
>
> - **Price Match: "Original flyer" now opens the store's own page for the product** (new tab, `noopener`). It is hidden when the store has no page for the item. Nothing links to Flipp (main already dropped the Flipp links in #20; this puts the store link on the Original flyer button instead of the "View on {store}'s site" line).
> - **Ad-tracker links are never shown as a store page.** Flipp routes some stores' tiles through `ad.doubleclick.net` click-trackers (357 Food Basics listings in the Toronto feed) that land on a generic flyer page with Flipp's UTM tags. One `clean_store_url()` in `models.py` now rejects `doubleclick.net`, `googleadservices.com`, `flipp.com` and `wishabi.*`. It runs when parsing (`flipp.store_url`) and as a validator on `FlyerItem`, so feeds already saved on disk by an older parser are cleaned without a refetch.
>
> ## Things to know
> - Chains with no store link get no button: Safeway, Save-On-Foods, FreshCo and Buy-Low (Flipp's `ttm_url` is null for them), about a third of Vancouver listings. No search URLs are guessed.
> - For T&T and PriceSmart the link Flipp gives is the store's own weekly-flyer page, not the single product, so it can't be exact. Superstore, No Frills, Independent and Walmart link to the exact product.
>
> ## Checks
> - `ruff` clean, `pytest` 244 passed
> - web: `tsc`, `eslint` clean, `vitest` 53 passed
> - Playwright: the four price-match / flyers tests pass (full e2e suite not re-run)
>
