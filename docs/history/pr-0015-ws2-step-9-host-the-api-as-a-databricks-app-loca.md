## Description

> app.yaml runs uvicorn on DATABRICKS_APP_PORT with the warehouse and API keys from app resources; requirements.txt is exported from uv.lock. When apps/web/.env.local sets DATABRICKS_APP_URL, a Next route proxies /api/* to the app and adds a token from 'databricks auth token' (Apps accept only OAuth; PATs can't be exchanged), server-side only. README documents create, deploy, laptop setup and the pre-judging restart.
