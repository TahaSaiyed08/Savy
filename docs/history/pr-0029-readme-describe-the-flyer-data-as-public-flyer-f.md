> ## What this does
>
> The README no longer names the flyer provider or shows its endpoints, hosts or file links. It now says "public flyer feeds" in the intro, how-it-works, the Databricks section, the architecture diagram, the layout list, the community text and the "Flyer data" section.
>
> - The "Flyer data" section keeps the facts that matter: the feeds are not an official API, the client is polite (identifying User-Agent, 20 s timeout, one retry, at most six requests at once), and the data is best treated as demo data.

> - `make flyer-snapshot` is added as an alias of the existing snapshot command, so the README can document it without the old name. The old command still works.
>
> ## Not changed
