## Description

> ## Summary
> - \`--label-2\` (iOS's secondaryLabel, used for all subtitles/secondary text) measures ~3.3-3.4:1 against \`--bg\`/\`--elevated\` in light mode at its default 0.6 alpha — below WCAG AA's 4.5:1 for normal text.
> - Bumped to 0.75, verified by computing the actual contrast ratios (not guessed): ~4.9:1 against \`--bg\` (#f2f2f7), ~5.2:1 against \`--elevated\` (#fff).
> - Dark mode's 0.6 already clears AA comfortably (~6:1+ against both black and elevated) and is untouched.
> - Verified visually in both light and dark mode — still reads clearly as secondary text next to \`--label\`, just no longer washed out.
>
> ## Why its own branch/PR
> Design (Varun) owns token *values* per \`docs/plan.md\`'s frozen interface — normally this is his call, not WS3's. He's not available right now, so this is split out from \`ws3/polish\` rather than folded in, for a clean, reviewable, single-purpose change.
